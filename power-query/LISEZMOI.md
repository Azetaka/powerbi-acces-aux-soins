# Requêtes Power Query

Coller ici le code M de chaque requête, un fichier par requête :

- `Base_Effectifs.m`
- `F_Effectifs.m`
- `F_Densite.m`
- `F_Honoraires.m`
- `D_Annee.m`
- `D_Departement.m`
- `D_Profession.m`
- `D_Age.m`

Pour récupérer le code : ouvrir la requête dans Power Query, puis **Accueil > Éditeur avancé**, tout sélectionner et copier.
